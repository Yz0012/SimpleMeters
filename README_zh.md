# 安装

完全不需要安装，因为项目只有单独的exe和vst3文件(准备)

# 使用
- 对于发布的exe文件
  - 左上角打开\关闭WASAPI回环，窗口内右键选择对应的组件即可创建组件进行分析

# 项目配置 

项目根目录下有 .jucer 后缀的文件
用Projucer打开.jucer文件后，在全局设置中指定下载的JUCE库根目录，确保所有模块引用正确
